# `results/` — the evidence trail

The course rubric says *every reported number can be traced to the logs in the
repository*. That is what this directory is for.

```
results/
├── raw/            one CSV per measurement session, committed
│   └── <timestamp>-<host>.csv
│       bench,mode,wall_s,vmpeak_kb,vmhwm_kb,vmsize_kb,checksum
├── summary.csv     generated by scripts/summarize.py
├── summary.md      generated — paste-ready tables for the report
└── figures/        generated by scripts/figures.py — Fig. 1 and Fig. 2, SVG + PDF
```

## Rules

1. **Never edit a raw CSV by hand.** If a run was invalid, delete the file and
   say why in the commit message, or keep it and mark the session in `../docs/`.
2. The filename carries the timestamp and hostname, so two sessions are never
   confused.
3. The `checksum` column must be identical across `base`, `asan` and `asanw` for
   a given benchmark. If it is not, the builds are not computing the same thing
   and the timings must be discarded.
4. Commit raw CSVs — they are a few kilobytes. Do **not** add them to
   `.gitignore`.
